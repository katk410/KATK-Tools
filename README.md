# KATK Tools

Bộ script tự động thiết lập Windows — DEV BY KATK.

Trang giới thiệu: https://katk.io.vn

## Cách dùng

Mở **PowerShell / Terminal (Admin)** và chạy:

```powershell
irm https://katk.io.vn | iex
```

Link dự phòng (chạy thẳng từ GitHub):

```powershell
irm https://raw.githubusercontent.com/katk410/KATK-Tools/stable/KATK.ps1 | iex
```
